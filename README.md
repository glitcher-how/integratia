# QA / E2E Repository for MQTT Migration

Этот архив подготовлен как отдельный пакет для тестировщиков и преподавателя.

Что внутри:
- описание архитектуры и систем проекта;
- инвентаризация ключевых директорий и файлов;
- два E2E-сценария с трассировкой по шагам;
- инструкция по запуску тестов после миграции с Kafka на MQTT;
- перечень заглушек, которые использовались для демонстрационного E2E;
- утилиты `fake_gcs.py` и `fake_gcs_mqtt.py` для воспроизведения стенда.

## Быстрый старт

1. Распаковать архив рядом с проектом `kafka_original`.
2. Прочитать `docs/01_testing_overview.md`.
3. Поднять окружение по `docs/05_launch_guide.md`.
4. Запустить:

```bash
pytest tests/e2e/test_e2e_scenario.py -v -s
```

## Что важно сказать на защите

- Основная цель работы — переход с Kafka на MQTT без потери интеграционной связности.
- Основной технический контур подтверждён E2E и unit/integration тестами.
- Для отсутствующих внешних частей стенда использовались заглушки DroneAnalytics и GCS.
- Поэтому сценарии считаются пройденными в демонстрационном интеграционном режиме, а не как полностью промышленный сертификационный стенд.
