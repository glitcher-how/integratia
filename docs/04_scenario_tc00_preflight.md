# 04. E2E-сценарий TC-00 — Допуск системы (Pre-flight)

## Цель
Подтвердить, что экосистема готова к выполнению миссии и регулятор разрешает запуск.

## Предусловия
- подняты основные компоненты экосистемы;
- доступен брокер сообщений MQTT;
- доступен регулятор;
- для демонстрационного стенда доступны mock DroneAnalytics и mock GCS.

## Трассировка сценария на текущий E2E

| Шаг TC-00 | Статус | Как подтверждается |
|---|---|---|
| Регистрация участников | Частично покрыт | `Test0_SystemsInRegulator::test_register_systems` |
| Связка сущностей | Частично покрыт | регистрация оператора/дрона + обработка заказа |
| Регистрация в брокере | Покрыт | MQTT bus + E2E + integration tests |
| Сертификаты регулятора | Частично покрыт | `register_drone_cert`, `register_operator_cert`, `verify_*` |
| Телеметрия и команды | Частично покрыт | request/response через MQTT, события в аналитике |
| Проверка страхования | Не полностью подтверждён | отдельная система есть, полный бизнес-полис в E2E явно не валидируется |
| Согласование с ОрВД | Частично подтверждён | участие `orvd_system` ожидается архитектурно, но не полностью доказано текущим архивом |
| Допуск регулятора | Частично покрыт | регулятор отвечает, проверки сертификатов проходят |

## Вывод по сценарию

Сценарий TC-00 можно заявлять как **частично пройденный в техническом E2E-контуре**. Корректно говорить, что:
- инфраструктура обмена и регистрации работает;
- регуляторные проверки базового уровня выполняются;
- полный сертификационный контур не моделировался в промышленной полноте.

## Что сказать устно

> Сценарий pre-flight был покрыт частично. Мы подтвердили регистрацию систем, работу MQTT-брокера, обмен сообщениями, доступность регулятора и базовые проверки сертификатов. Полный промышленный цикл страхования, ОрВД и регуляторного допуска не моделировался целиком, поэтому сценарий считаем выполненным в демонстрационном интеграционном режиме.
