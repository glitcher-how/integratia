# 05. E2E-сценарий 1 — Нормальная миссия

## Цель
Проверить сквозное выполнение миссии от создания заказа до результата при штатной работе основных компонентов.

## Что ожидается по сценарию
1. Создать заказ.
2. Передать заказ на исполнение.
3. Подобрать допустимый БАС/исполнителя.
4. Проверить регуляторные условия.
5. Обеспечить страхование.
6. Сформировать миссию.
7. Зарегистрировать миссию в ОрВД.
8. Подготовить БАС / GCS / SITL контур.
9. Получить авторизацию вылета.
10. Выполнить миссию.
11. Зафиксировать результат.
12. Закрыть заказ.

## Трассировка на текущий `tests/e2e/test_e2e_scenario.py`

| Этап | Статус | Доказательство |
|---|---|---|
| Создание заказчика и заказа | Покрыт | `Test3_OrderMissionAndGCS` |
| Передача заказа в обработку | Частично покрыт | заказ получает статус и движется по цепочке агрегатора |
| Подбор дрона | Частично покрыт | статус `matched` |
| Подтверждение цены | Покрыт | `/orders/{id}/confirm-price` |
| Планирование маршрута | Покрыт в demo-режиме | MQTT request `plan_mission_route` -> `systems.gcs` |
| Завершение заказа | Покрыт | `/orders/{id}/confirm-completion` |
| Проверка статуса заказа | Покрыт | `GET /orders/{id}` -> `completed` |
| Фиксация событий в аналитике | Покрыт | `TestLogVerification` |

## Что покрыто только частично или через mock

| Подсистема | Статус |
|---|---|
| GCS gateway | mock |
| GCS MQTT planner | mock |
| DroneAnalytics | mock |
| SITL | не моделировался как полноценный контур |
| Реестр | не подтверждён как полноценный business ledger |
| Страховой полис | не доказан end-to-end в текущем тесте |
| ОрВД полный цикл | не доказан полностью |

## Вывод по сценарию

Сценарий «Нормальная миссия» можно показывать как **демонстрационный E2E после миграции на MQTT**. Корректная формулировка:

> Мы подтвердили создание заказа, подбор исполнителя, построение маршрута, завершение заказа и запись событий в аналитику. Для недостающих внешних сервисов были использованы mock-заглушки, поэтому сценарий прошёл как демонстрационный интеграционный E2E, а не как полный промышленный flight-операционный контур.
